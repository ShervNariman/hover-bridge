## Controls
1. Read the repository and linked Linear issue before editing.
2. Preserve the tiny, dependency-light utility wedge and avoid unrelated expansion.
3. Run native lint, typecheck, tests, build, and browser interaction checks.
4. Preserve recording routes and required before/after launch artifacts.
5. Do not capture sensitive inputs or recording-route activity in analytics.
6. Production deploys, publishing, credentials, billing, and destructive changes require human approval.
7. Document validation, remaining risks, rollback, screenshots, and demo assets for each release.
8. Missing capabilities fail closed and must be reported explicitly.

Activation is meaningful demo interaction or implementation copy.
